Локальный мультимодальный ИИ-конвейер для анализа FinTech и UML документации

Интеллектуальная система (Vision-to-Text-to-Text) на базе современных моделей Qwen2.5-VL и Qwen2.5 (1.5B) для автоматического распознавания, оцифровки и глубокого анализа сложных визуальных данных: финансовых отчетов, графиков выручки, сканов чеков и UML-диаграмм.

Ключевые результаты и оптимизация
- Ускорение работы в 60 раз: Оптимизировала пайплайн обработки тяжелых PDF. За счет внедрения точечного извлечения целевых страниц через `pdf2image`/`poppler` время анализа сократилось с 1.5 часов до 1.5 минут.
- Умный инференс (Chain-of-Thought): Настроила специализированные инженерные промпты, заставив модель детально разбирать структуру данных схемы (классы, атрибуты, типы данных, связи `trace`), избегая стандартной лени VLM-моделей.
- Синтетическая разметка: Архитектура подготовлена для генерации и выгрузки специализированных финтех-датасетов в формате JSONL под последующее дообучение (Fine-tuning через LoRA/PEFT).

Технологический стек
- AI/LLM:** Ollama API, Qwen2.5-VL (зрячая модель), Qwen2.5:1.5b (текстовый аналитик).
- Backend & API:** Python, FastAPI, Pydantic, Uvicorn (Архитектура REST API).
- Data Processing & OCR: pdf2image, Pillow, Poppler.
- Тестирование: Postman, Python-клиенты.

Архитектура взаимодействия (Пайплайн)
1. FastAPI Server (`main.py`)принимает REST-запрос от пользователя (путь к PDF, номер страницы, аналитический вопрос).
2. Мультимодальный движок (`ai_engine.py`) делает мгновенный "прыжок" к нужной странице и конвертирует её в изолированный JPG-изображение.
3. Qwen2.5-VL выступает в роли продвинутого ИИ-OCR: анализирует пиксели, извлекает сущности, типы данных и связи в текстовый контекст.
4. Qwen2.5 (1.5B) объединяет извлеченный визуальный контекст с вопросом пользователя и генерирует финальный структурированный ответ.

Как запустить проект

1. Установите зависимости:
bash
pip install -r requirements.txt

2. Убедитесь, что в Ollama скачаны модели 'qwen2.5-vl' и 'qwen2.5:1.5b'.
3. Запустите API-сервер:
bash
python main.py

4. В другом терминале запустите клиент для проверки контрольного задания:
bash
python ai_newchat.py
